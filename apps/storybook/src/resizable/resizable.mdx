# Resizable

Grupos de painéis redimensionáveis, com suporte a teclado.

<Canvas of={ResizableStories.Demo} />

## Sobre

O `Resizable` usa o [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels), de bvaughn, e não um primitivo do Base UI. A API de props de `ResizablePanelGroup`, `ResizablePanel` e `ResizableHandle` é a dele (versão 4).

## Instalação

O Resizable usa o `react-resizable-panels` e o `cn`.

<Source language="bash" dark code="npx shadcn add resizable" />

Ele já está no pacote, mas, para reinstalar, rode o comando dentro de `packages/ui`. O CLI usa o `shadcn` local (versão fixa) e sobrescreve o arquivo com o estilo do preset: depois, reaplique as decisões anotadas no comentário do topo do componente.

O componente está no pacote `@workspace/ui`, em `packages/ui/src/components/resizable.tsx`.

## Uso

<Source
  language="tsx"
  dark
  code={`import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@workspace/ui/components/resizable"

<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel>Um</ResizablePanel>
  <ResizableHandle aria-label="Redimensionar o painel Um" />
  <ResizablePanel>Dois</ResizablePanel>
</ResizablePanelGroup>`}
/>

## Acessibilidade

- **Nome do handle:** o `ResizableHandle` é um `role="separator"` focável, e um controle focável precisa de nome. O componente já traz o padrão "Redimensionar painéis". Quando houver mais de um handle na tela, dê a cada um um `aria-label` específico e diferente ("Redimensionar a barra lateral"), como nos exemplos.
- **Teclado:** Tab chega ao handle e as setas redimensionam os painéis vizinhos. O handle expõe `aria-valuenow` (o tamanho do painel, em %), `aria-valuemin`, `aria-valuemax` e `aria-orientation`, que o leitor de tela anuncia. Em RTL, o sentido das setas segue a direção da página. Quem só usa o teclado consegue fazer tudo o que o mouse faz.
- **Foco:** o anel é sólido, de 3px, no token `--ring`, afastado 2px pela cor do fundo. Como a linha do handle tem 1px, o anel a envolve e o handle sobe na pilha ao receber foco (`z-10`), para não ficar sob o conteúdo dos painéis vizinhos. O contêiner do grupo corta o que passa das suas bordas, então nas pontas da linha o anel é aparado.
- **Linha e pegada:** a linha de 1px do handle (`bg-border`) é decorativa. A pegada (`withHandle`) usa `bg-input`, para ter pelo menos 3:1 como algo que se arrasta (4,6:1 no branco e 3,8:1 no escuro na Brainz Group). Ela leva `aria-hidden`, e o controle é anunciado pelo `role="separator"`, não pelo desenho.
- **Painéis:** o conteúdo de cada painel segue as regras do próprio conteúdo. Um painel que rola precisa ser alcançável pelo teclado (veja a página do Scroll Area).
- **Zoom a 200%:** confira que os painéis continuam usáveis e que o handle continua alcançável.

<Source
  language="tsx"
  dark
  code={`<ResizableHandle withHandle aria-label="Redimensionar a barra lateral" />`}
/>

## Vertical

Use `orientation="vertical"` para redimensionar na vertical. O handle vira uma linha horizontal e as setas para cima e para baixo redimensionam.

## RTL

A linha, a área de clique e a pegada são lógicas, então o grupo segue a direção de um ancestral com `dir="rtl"`. O exemplo usa `dir` no próprio grupo porque esta página é LTR. Para ver a página inteira em RTL, use o seletor **Direção** na barra de ferramentas. Veja também o [guia de RTL do shadcn](https://ui.shadcn.com/docs/rtl).

Veja a [documentação do react-resizable-panels](https://github.com/bvaughn/react-resizable-panels) para a lista completa. As principais:

Aceita as props de um `<div>`.

### ResizableHandle

Aceita as props do `Separator` do react-resizable-panels.

<ScrollTable label="Resizable: ResizableHandle">
