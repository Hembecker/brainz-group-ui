# Kbd

Mostra uma tecla do teclado, ou um atalho.

<Canvas of={KbdStories.Demo} />

## Instalação

O Kbd não tem dependências além do `cn`.

<Source language="bash" dark code="npx shadcn add kbd" />

Ele já está no pacote, mas, para reinstalar, rode o comando dentro de `packages/ui`. O CLI usa o `shadcn` local (versão fixa) e sobrescreve o arquivo com o estilo do preset: depois, reaplique as decisões anotadas no comentário do topo do componente.

O componente está no pacote `@workspace/ui`, em `packages/ui/src/components/kbd.tsx`.

## Uso

<Source
  language="tsx"
  dark
  code={`import { Kbd, KbdGroup } from "@workspace/ui/components/kbd"

<Kbd>Ctrl</Kbd>`}

## Acessibilidade

- **Estático:** o `Kbd` é só um `<kbd>` de texto: não recebe foco e não executa o atalho. Quem executa é o seu código (um `keydown`, o `accesskey` ou o atalho do componente). Mostrar o atalho não substitui a ação por mouse e por toque: o controle continua alcançável sem o atalho.
- **Nome dos símbolos:** os símbolos (⌘ ⇧ ⌥ ⌃ ⏎) não têm um nome falado confiável: um leitor de tela pode ler "sinal de lugar de interesse", ou nada. Marque o símbolo com `aria-hidden="true"` e escreva o nome da tecla num `sr-only` ao lado ("Command", "Shift", "Enter"), como nos exemplos. Evite o `aria-label` direto no `<kbd>`: o elemento não tem papel, e o ARIA proíbe o nome em elementos sem papel. Teclas de texto (`Ctrl`, `K`) já são lidas direito.
- **Atalho no controle:** para o leitor de tela saber o atalho, ligue o atalho ao controle com `aria-keyshortcuts` (por exemplo `aria-keyshortcuts="Control+S"` num botão de salvar), além de mostrar o `Kbd`. O `Kbd` sozinho só comunica visualmente.
- **Separador:** o `+` entre as teclas é só visual: leva `aria-hidden="true"`.
- **Contraste** (texto da tecla sobre o fundo, nos dois modos):
  - padrão, `muted-foreground` sobre `muted`: 6,6:1 no claro e 6,1:1 no escuro. Dentro de um Button, a tecla mantém o chip `muted`, então o mesmo contraste vale em qualquer variante;
  - dentro de um **Input Group**, `muted-foreground` sobre `muted` no claro (6,6:1 na Brainz, 5,3:1 no SESI) e sobre `background` no escuro (8,1:1). O registro usava `bg-input`, que dava 1,6:1 e 2,1:1 com esse texto; o `InputGroupAddon` aplica as mesmas cores, e o próprio `Kbd` concorda. O `bg-background` sumia no campo branco do SESI claro (1:1). O chip contra o campo (`field`) tem 1,25:1 e 1,33:1: é decorativo, o texto é que vale;
  - dentro de um **Tooltip** (fundo `foreground`), `text-background` sobre `muted-foreground`: 7,4:1 e 8,1:1, um papel cheio nos dois modos. O registro usava `bg-background/20` e `/10`, com uma variante `dark:`. O chip contra o tooltip tem 2,7:1 e 2,4:1, também decorativo.
- **Ícones decorativos:** um ícone dentro do `Kbd` leva `aria-hidden="true"`.
- **Zoom:** o `Kbd` tem altura fixa de 20px (`h-5`, 1,25rem, que acompanha o zoom do navegador) e largura mínima de 20px (`min-w-5`), que cresce com o texto; confira o zoom a 200%.

## Button

Use o `Kbd` dentro de um `Button` para mostrar uma tecla no botão. Dê `data-icon="inline-end"` ao `Kbd` para o botão reduzir o padding daquele lado.

<Canvas of={KbdStories.Botao} />

## Tooltip

Use o `Kbd` dentro de um `Tooltip` para mostrar um tooltip com uma tecla. O tooltip é só um complemento visual: o botão já tem o nome pelo texto dele. Quando o atalho existir de fato no seu código, ligue-o ao botão com `aria-keyshortcuts` (veja Acessibilidade). O exemplo só mostra as teclas e não registra atalho nenhum, por isso não declara o atributo.

<Canvas of={KbdStories.ComTooltip} />

## Input Group

Use o `Kbd` dentro de um `InputGroupAddon` para mostrar uma tecla num grupo de campo. O campo mantém o rótulo persistente (`FieldLabel` ligado ao `id`).

<Canvas of={KbdStories.ComInputGroup} />

## RTL

O `Kbd` e o `KbdGroup` usam `gap` e `inline-flex`, sem direção fixa, então seguem a de um ancestral com `dir="rtl"`: a ordem das teclas inverte. O exemplo usa `dir` num `div` porque esta página é LTR. Para ver a página inteira em RTL, use o seletor **Direção** na barra de ferramentas. Veja também o [guia de RTL do shadcn](https://ui.shadcn.com/docs/rtl).

## Referência da API

### Kbd

Mostra uma tecla do teclado. Aceita todas as props de um `<kbd>`.

<ScrollTable label="Referência da API do Kbd">

  </table>

O elemento recebe `data-slot="kbd"`. Dentro de um Tooltip ele usa `in-data-[slot=tooltip-content]`, e dentro de um Input Group, `in-data-[slot=input-group]`.

### KbdGroup

Agrupa componentes `Kbd`. O tipo das props é o de um `<div>`, mas o elemento renderizado é um `<kbd>` (herdado do registro).
