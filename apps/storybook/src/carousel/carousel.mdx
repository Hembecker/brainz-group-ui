# Carousel

Um carrossel com movimento e gesto de arrastar, feito com o Embla.

<Canvas of={CarouselStories.Demo} />

## Sobre

O Carousel usa a biblioteca [Embla Carousel](https://www.embla-carousel.com/). As opções (`opts`), os plugins e a API vêm direto dela: veja a [documentação do Embla](https://www.embla-carousel.com/api/) para a lista completa.

## Instalação

O Carousel usa o `embla-carousel-react`, o Button e o ícone do `lucide-react`.

<Source language="bash" dark code="npx shadcn add carousel" />

Ele já está no pacote, mas, para reinstalar, rode o comando dentro de `packages/ui`. O CLI usa o `shadcn` local (versão fixa) e sobrescreve o arquivo com o estilo do preset: depois, reaplique as decisões anotadas no comentário do topo do componente.

O componente está no pacote `@workspace/ui`, em `packages/ui/src/components/carousel.tsx`.

## Acessibilidade

O Carousel segue o padrão de carrossel do WAI-ARIA.

- **Região com nome:** o contêiner é uma região com `aria-roledescription="carousel"`. Ele **precisa de um nome**, que o componente não tem como adivinhar: passe `aria-label` ou `aria-labelledby` ("Destaques da semana"). Com vários carrosséis na página, cada um leva um nome diferente.
- **Slides com nome:** cada `CarouselItem` é um grupo com `aria-roledescription="slide"` e o nome automático "1 de 5", calculado pela posição e pelo total (os itens contam como filhos diretos, em arrays ou em Fragments; um item escondido dentro de outro componente não é contado, e então leva um `aria-label` próprio). Para um nome mais específico ("Plano Pro"), passe `aria-label` no item: ele tem preferência.
- **Botões com nome:** "Slide anterior" e "Próximo slide" (texto `sr-only`), e as setas levam `aria-hidden="true"`. O nome é fixo em português; para outro idioma, passe `aria-label` no botão (veja **RTL**). No primeiro slide o anterior fica desabilitado, e no último, o próximo (a menos que use `loop`). O botão desabilitado continua focável (`focusableWhenDisabled`): recebe `aria-disabled="true"` e `data-disabled`, no lugar do `disabled` nativo, e fica na ordem do `Tab`. Assim, quem avança pelo teclado até o último slide continua no botão, o foco não cai no `<body>` e as setas continuam funcionando.
- **Teclado:** `Tab` chega aos botões, e as setas ← e → trocam de slide quando o foco está dentro do carrossel. Em RTL as setas espelham (← avança). Quando o foco está num campo ou num widget que já usa as setas dentro de um slide (texto, select, slider, grupo de rádio, lista, menu, grade), as setas ficam com ele e não trocam de slide. O anel de foco é o do Button: sólido, no token `--ring`, afastado 2px pela cor do fundo.
- **Sem reprodução automática:** o conteúdo que se move sozinho precisa de um controle para pausar (WCAG 2.2.2). O padrão é não ter autoplay. Se usar o plugin de autoplay (veja **Plugins**), ofereça um botão de pausar, pare a rolagem quando o foco ou o mouse entrar no carrossel e comece pausado com `prefers-reduced-motion: reduce`. Mantenha o `aria-live` do conteúdo em `off` enquanto gira e em `polite` quando parado.
- **Mudanças dinâmicas:** quem usa a API para mostrar "Slide 2 de 5" deve manter essa região `aria-live="polite"` (`role="status"`) sempre montada, trocando só o texto (veja **API**).
- **Cor e contraste:** os botões são o Button `outline`, com texto e contorno nos papéis do sistema. O conteúdo dos slides segue as regras de cada componente.

## API

Use um estado e a prop `setApi` para obter a instância da API do carrossel. O exemplo mostra "Slide 2 de 5" numa região `role="status"` que fica sempre montada: só o texto muda, e o leitor de tela anuncia a troca.

## Eventos

Escute os eventos pela instância de `setApi`. Veja a [documentação dos eventos](https://www.embla-carousel.com/api/events/).

<Source
  language="tsx"
  dark
  code={`import { type CarouselApi } from "@workspace/ui/components/carousel"

export function Exemplo() {
  const [api, setApi] = React.useState<CarouselApi>()

  React.useEffect(() => {
    if (!api) {
      return
    }

    const aoSelecionar = () => {
      // Faça algo quando o slide mudar.
    }
    api.on("select", aoSelecionar)

    return () => {
      api.off("select", aoSelecionar)
    }
  }, [api])

  return (
    <Carousel setApi={setApi} aria-label="Destaques da semana">
      <CarouselContent>
        <CarouselItem>...</CarouselItem>
        <CarouselItem>...</CarouselItem>
        <CarouselItem>...</CarouselItem>
      </CarouselContent>
    </Carousel>
  )
}`}
/>

## Plugins

Use a prop `plugins` para adicionar plugins do Embla, como o de reprodução automática (`embla-carousel-autoplay`). Veja a [documentação do plugin](https://www.embla-carousel.com/plugins/autoplay/).

<Source
  language="bash"
  dark
  code="npm.cmd install embla-carousel-autoplay@8.6.0 -w <workspace>"
/>

Use a mesma versão do `embla-carousel-react` (8.6.0) e fixe a versão exata, sem `^`. No Storybook, o pacote é dependência de `@workspace/storybook`.

O exemplo do shadcn só chama `stop` ao passar o mouse, o que não serve para quem usa o teclado nem cumpre a WCAG 2.2.2. O exemplo abaixo segue o padrão de carrossel com rotação automática do WAI-ARIA:

- **Botão de pausar** visível, antes dos slides na ordem de leitura. O nome troca entre "Pausar a rotação automática" e "Retomar a rotação automática" (o nome muda, então não use `aria-pressed` junto).
- **A rotação para** quando o mouse ou o foco do teclado entra no carrossel (os botões dos slides contam) e volta quando sai, a menos que a pessoa tenha pausado.
- **Movimento reduzido:** com `prefers-reduced-motion: reduce`, o carrossel começa pausado.
- **Região ao vivo:** o `CarouselContent` fica com `aria-live="off"` enquanto gira, para o leitor de tela não anunciar cada troca, e com `aria-live="polite"` quando está parado.

O estado (pausa, mouse, foco) fica no React, e um efeito chama `plugin.play()` ou `plugin.stop()`. Por isso o plugin é criado com `playOnInit: false`, `stopOnInteraction: false` e `stopOnFocusIn: false`, e o `loop` fica ligado nas opções.

## RTL

Em RTL, o Embla precisa da opção `direction`, porque ele não lê o `dir` do DOM. O Carousel usa a direção do `DirectionProvider` quando `opts.direction` não é passada; no exemplo ela vem explícita, como na página do shadcn. Use também `dir="rtl"` no carrossel.

Os botões já espelham as setas (`rtl:rotate-180` no ícone), então não repita a classe nos botões: as duas se anulariam. No modo vertical o botão já gira 90° e o espelhamento não vale. As setas do teclado também espelham. O nome dos botões é fixo em português, então, em outro idioma, passe `aria-label` neles, e também nos itens, como no exemplo.

## Referência da API

### Carousel

O contêiner raiz. É uma região (`role="region"`) com `aria-roledescription="carousel"`. Aceita todas as props de um `<div>`, e o `aria-label` é obrigatório na prática.

<table>
  <thead>
    <tr><th>Prop</th><th>Tipo</th><th>Padrão</th></tr>
  </thead>
  <tbody>
    <tr><td><code>orientation</code></td><td><code>{'"horizontal" | "vertical"'}</code></td><td><code>{'"horizontal"'}</code></td></tr>
    <tr><td><code>opts</code></td><td><code>CarouselOptions</code> (opções do Embla)</td><td>direção do <code>DirectionProvider</code></td></tr>
    <tr><td><code>plugins</code></td><td><code>CarouselPlugin</code> (plugins do Embla)</td><td>—</td></tr>
    <tr><td><code>setApi</code></td><td><code>{'(api: CarouselApi) => void'}</code></td><td>—</td></tr>
    <tr><td><code>aria-label</code> / <code>aria-labelledby</code></td><td><code>string</code></td><td>— (passe um dos dois)</td></tr>
    <tr><td><code>className</code></td><td><code>string</code></td><td>—</td></tr>
  </tbody>
</table>

O elemento recebe `data-slot="carousel"`. Veja a [documentação do Embla](https://www.embla-carousel.com/api/) para as opções e os plugins.

### CarouselContent

Envolve os itens e é o elemento que o Embla move. Aceita as props de um `<div>`; a `className` vai para a faixa interna (use para o espaçamento e a altura no vertical). Passa a posição e o total para cada item, para o nome automático. Recebe `data-slot="carousel-content"`.

### CarouselItem

Um slide. É um grupo (`role="group"`) com `aria-roledescription="slide"` e `aria-label` automático "n de total". Aceita as props de um `<div>`, e um `aria-label` próprio tem preferência. Recebe `data-slot="carousel-item"`.

### CarouselPrevious e CarouselNext

Os botões de navegação, com o nome "Slide anterior" e "Próximo slide". Aceitam as props do Button.

<table>
  <thead>
    <tr><th>Prop</th><th>Tipo</th><th>Padrão</th></tr>
  </thead>
  <tbody>
    <tr><td><code>variant</code></td><td>variantes do Button</td><td><code>{'"outline"'}</code></td></tr>
    <tr><td><code>size</code></td><td>tamanhos do Button</td><td><code>{'"icon-sm"'}</code></td></tr>
    <tr><td><code>aria-label</code></td><td><code>string</code></td><td>texto <code>sr-only</code> em português</td></tr>
  </tbody>
</table>

Recebem `data-slot="carousel-previous"` e `data-slot="carousel-next"`. Nas pontas, recebem `aria-disabled="true"` e `data-disabled` (com `focusableWhenDisabled`), sem o `disabled` nativo: num teste, confira `aria-disabled` e não `toBeDisabled()`.

### useCarousel

Um hook, só para uso dentro do `Carousel`, que devolve a API do Embla, `scrollPrev`, `scrollNext`, `canScrollPrev`, `canScrollNext`, `orientation` e `opts`.

O tipo `CarouselApi` também é exportado, para tipar o estado do `setApi`.
