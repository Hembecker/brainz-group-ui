# Aspect Ratio

Mostra um conteúdo dentro de uma proporção definida.

<Canvas of={AspectRatioStories.Demo} />

Os exemplos usam o logo da Brainz Group, que o Storybook serve a partir de `brand/`, no lugar das fotos externas do shadcn.

## Instalação

O Aspect Ratio não tem dependências além do `cn`. Ele é só um `<div>` com a proporção reservada pelo CSS.

<Source language="bash" dark code="npx shadcn add aspect-ratio" />

Ele já está no pacote, mas, para reinstalar, rode o comando dentro de `packages/ui`. O CLI usa o `shadcn` local (versão fixa) e sobrescreve o arquivo com o estilo do preset: depois, reaplique as decisões anotadas no comentário do topo do componente.

O componente está no pacote `@workspace/ui`, em `packages/ui/src/components/aspect-ratio.tsx`.

## Uso

<Source
  language="tsx"
  dark
  code={`import { AspectRatio } from "@workspace/ui/components/aspect-ratio"

<AspectRatio ratio={16 / 9}>
  <img
    src="/capa.jpg"
    alt="Capa do relatório trimestral"
    className="absolute inset-0 size-full rounded-2xl object-cover"
  />
</AspectRatio>`}
/>

O `AspectRatio` é `relative`, então o filho que preenche o espaço leva `absolute inset-0 size-full`. No Next.js, o `fill` do componente `Image` faz o mesmo.

## Acessibilidade

- **Sem papel próprio:** o `AspectRatio` é um `<div>` de layout. Ele não tem papel, nome nem foco, e não deve receber `aria-label`. Quem tem nome é o conteúdo de dentro.
- **Imagem:** uma imagem que informa algo leva `alt` com essa informação ("Capa do relatório trimestral"), nunca "foto" nem o nome do arquivo. Uma imagem só decorativa leva `alt=""`.
- **Legenda:** para uma legenda visível, envolva o `AspectRatio` e o texto num `<figure>` com `<figcaption>`. O leitor de tela liga a legenda à imagem.
- **Vídeo e incorporações:** um `<iframe>` ou `<video>` dentro do `AspectRatio` precisa do próprio nome (`title` no iframe) e, se tiver controles, dos controles acessíveis por teclado.
- **Proporção e zoom:** a proporção é de caixa, não de texto. Não ponha texto corrido num `AspectRatio` com altura fixa: com o zoom a 200% ele ficaria cortado. Para texto, use o conteúdo na altura natural.
- **Cor:** o componente não tem cor. O fundo `bg-muted` dos exemplos aparece enquanto a imagem carrega; o contraste do conteúdo que ele recebe é o do próprio conteúdo.

<Source
  language="tsx"
  dark
  code={`<figure className="w-full max-w-sm">
  <AspectRatio ratio={16 / 9} className="rounded-2xl bg-muted">
    <img
      src="/capa.jpg"
      alt="Capa do relatório trimestral"
      className="absolute inset-0 size-full rounded-2xl object-cover"
    />
  </AspectRatio>
  <figcaption className="mt-2 text-center text-sm text-muted-foreground">
    Relatório do terceiro trimestre
  </figcaption>
</figure>`}
/>

## Quadrado

Use `ratio={1 / 1}` para um formato quadrado, útil para miniaturas e fotos de perfil. O logo é horizontal, então o exemplo usa `object-cover object-left` para mostrar só o início dele.

## RTL

O `AspectRatio` não tem espaçamento nem alinhamento, então a proporção é a mesma em RTL. O que muda é o conteúdo ao redor, como a legenda, que segue a direção de um ancestral com `dir="rtl"`. O `alt` e a legenda ficam no idioma da página.

Num app em RTL, coloque `dir="rtl"` e o `lang` no `<html>`. O exemplo usa um `figure` com `dir` porque esta página é LTR. Para ver a página inteira em RTL, use o seletor **Direção** na barra de ferramentas. Veja também o [guia de RTL do shadcn](https://ui.shadcn.com/docs/rtl).

## Referência da API

### AspectRatio

Reserva um espaço com a proporção pedida e posiciona o conteúdo dentro dele. Aceita todas as props de um `<div>`.

<ScrollTable label="Aspect Ratio: AspectRatio">

O elemento recebe `data-slot="aspect-ratio"` e a variável CSS `--ratio`. O `style` passado é mesclado com ela, e o `--ratio` sempre vem da prop `ratio`.
