# Spinner

Um indicador que mostra que algo está carregando.

<Canvas of={SpinnerStories.Demo} />

## Instalação

O Spinner usa o ícone `Loader2Icon` do `lucide-react`.

<Source language="bash" dark code="npx shadcn add spinner" />

Ele já está no pacote, mas, para reinstalar, rode o comando dentro de `packages/ui`. O CLI usa o `shadcn` local (versão fixa) e sobrescreve o arquivo com o estilo do preset: depois, reaplique as decisões anotadas no comentário do topo do componente.

O componente está no pacote `@workspace/ui`, em `packages/ui/src/components/spinner.tsx`.

## Uso

<Source
  language="tsx"
  dark
  code={`import { Spinner } from "@workspace/ui/components/spinner"

<Spinner />`}
/>

## Acessibilidade

- **Rótulo:** o Spinner tem `role="status"` e o rótulo "Carregando". Use `aria-label` para dizer o que está carregando, por exemplo "Processando o pagamento".
- **Movimento:** quando o sistema pede movimento reduzido, o ícone fica parado.
- **Anúncio:** um Spinner que acaba de aparecer pode não ser anunciado, e o fim do carregamento não é anunciado. Para avisar que algo começou ou terminou, mantenha uma região `aria-live="polite"` sempre montada e troque só o texto dela. Reserve `aria-live="assertive"` para erros críticos.

<Source
  language="tsx"
  dark
  code={`const mensagens = {
  ocioso: "",
  salvando: "Salvando as alterações",
  salvo: "Alterações salvas",
  erro: "Não foi possível salvar as alterações",
}

<p aria-live="polite" aria-atomic="true" className="sr-only">
  {mensagens[status]}
</p>`}
/>

## Personalização

Para trocar o ícone, edite o componente e substitua o `Loader2Icon` por outro ícone. O exemplo mostra o `LoaderIcon` do `lucide-react` com a mesma API: `role="status"`, o rótulo e a animação, que fica parada com movimento reduzido.

<Canvas of={SpinnerStories.Personalizacao} />

O componente fica assim:

<Source
  language="tsx"
  dark
  code={`import { LoaderIcon } from "lucide-react"

<LoaderIcon
  data-slot="spinner"
  role="status"
  aria-label="Carregando"
  className={cn("size-4 animate-spin motion-reduce:animate-none", className)}
  {...props}
/>`}
/>

## Tamanho

Use as classes `size-*` para mudar o tamanho do spinner. A cor acompanha a cor do texto.

<Canvas of={SpinnerStories.Tamanho} />

## Button

Para mostrar que um botão está carregando, coloque o `<Spinner />` antes do rótulo com `data-icon="inline-start"` ou depois do rótulo com `data-icon="inline-end"`, e desabilite o botão.

<Canvas of={SpinnerStories.NoBotao} />

## Badge

Adicione um Spinner a um Badge com `data-icon="inline-start"` ou `data-icon="inline-end"`. O Badge já ajusta o espaçamento daquele lado.

<Canvas of={SpinnerStories.NoBadge} />

## Input Group

Coloque um Spinner num `InputGroupAddon`, ao lado de um campo. Enquanto ele gira, o campo fica desabilitado. O campo continua precisando de um nome (`aria-label`), porque o placeholder não é rótulo, e o Spinner leva um `aria-label` que diz o que está acontecendo.

<Canvas of={SpinnerStories.NoGrupoDeEntrada} />

## Empty

Use um Spinner no `EmptyMedia` para um estado de carregamento de página ou de seção. O `EmptyTitle` é um `div`, então coloque um heading dentro dele (veja o Empty).

<Canvas of={SpinnerStories.NoVazio} />

## RTL

O Spinner não tem lado: em RTL, ele só acompanha o fluxo do conteúdo ao redor. Dê a ele um `aria-label` no idioma da página.

Num app em RTL, coloque `dir="rtl"` e o `lang` no `<html>`. O exemplo usa um `div` com `dir` porque esta página é LTR. Para ver a página inteira em RTL, use o seletor **Direção** na barra de ferramentas. Veja também o [guia de RTL do shadcn](https://ui.shadcn.com/docs/rtl).

## Referência da API

### Spinner

Um indicador de carregamento. Renderiza o `Loader2Icon` do `lucide-react` e aceita todas as props de um `<svg>`, que são repassadas a ele.

<ScrollTable label="Referência da API do Spinner">
  <table>
    <thead>
      <tr><th>Prop</th><th>Tipo</th><th>Padrão</th></tr>
    </thead>
    <tbody>
      <tr><td><code>aria-label</code></td><td><code>string</code></td><td><code>{'"Carregando"'}</code></td></tr>
      <tr><td><code>className</code></td><td><code>string</code></td><td>—</td></tr>
    </tbody>
  </table>
</ScrollTable>

O elemento recebe `data-slot="spinner"` e `role="status"`; as props são repassadas por último, então as duas podem ser sobrescritas. O padrão é `size-4 animate-spin motion-reduce:animate-none`; a `className` é mesclada por cima. Dentro de um Button ou de um Badge, quem usa passa `data-icon="inline-start"` ou `"inline-end"`: o componente não define esse atributo.
