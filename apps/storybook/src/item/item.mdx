# Item

Um componente versátil para mostrar conteúdo com mídia, título, descrição e ações.

<Canvas of={ItemStories.Demo} />

O `Item` é um contêiner flex simples, que aceita quase qualquer conteúdo. Use-o para mostrar um título, uma descrição e ações. Agrupe vários com o `ItemGroup` para montar uma lista.

## Instalação

O Item usa o `Separator`, o `useRender` do Base UI e o `class-variance-authority`.

<Source language="bash" dark code="npx shadcn add item" />

Ele já está no pacote, mas, para reinstalar, rode o comando dentro de `packages/ui`. O CLI usa o `shadcn` local (versão fixa) e sobrescreve o arquivo com o estilo do preset: depois, reaplique as decisões anotadas no comentário do topo do componente.

O componente está no pacote `@workspace/ui`, em `packages/ui/src/components/item.tsx`.

## Acessibilidade

- **Link ou ação:** o Item é um `<div>` por padrão. Para navegar, use a prop `render` com um `<a href>`; para executar algo, use `render={<button type="button" />}`. Nunca deixe o `<div>` com `onClick`: ele não recebe foco nem responde ao teclado. O `render` troca o elemento (`useRender` do Base UI), sem um `div` envolvendo.
- **Nome acessível:** num Item que é link ou botão, o título e a descrição inteiros viram o nome do controle. Mantenha os dois curtos e comece pelo que diz a ação ou o destino. Um ícone de seta ou de link externo é decorativo e leva `aria-hidden="true"`; se o link abre numa nova aba, avise com um texto `sr-only` no título.
- **Botões de ação dentro do Item:** um botão só com ícone precisa de `aria-label` ou de texto `sr-only` com a ação e o alvo, como "Convidar Carla Souza". Num Item que já é link ou botão, não ponha outro controle dentro dele: um controle dentro do outro não é válido em HTML.
- **Grupo é lista:** o `ItemGroup` tem `role="list"`, então cada filho direto precisa de `role="listitem"`. Um Item comum recebe o papel direto. Um Item que é link **não** pode receber `role="listitem"` (o papel apagaria o de link): envolva-o num `<div role="listitem">`, como no exemplo **Imagem**.
- **ItemSeparator dentro do grupo:** o separador é um contêiner `role="none"` com a linha decorativa (`aria-hidden`) dentro, então a lista do `ItemGroup` continua contendo só itens. A separação é só visual; o leitor de tela anuncia a lista e os itens.
- **Imagens e avatares:** uma imagem ou um avatar que repete o texto ao lado é decorativo: `alt=""` na imagem e `aria-hidden="true"` no `Avatar`, para o leitor de tela não ler as iniciais antes do nome. Uma imagem que informa algo leva `alt` com essa informação.
- **Foco:** o anel é sólido, de 3px, no token `--ring`, e fica afastado 2px pela cor do fundo, como no Button. No link, o foco e o hover ficam no próprio `<a>`. Não remova o anel.
- **Hover:** o fundo no hover (`bg-muted`) só existe nos Items que são `<a>`. Um `<button>` não muda de fundo no hover, só mostra o foco. Na variante `muted`, o hover e o fundo são a mesma cor, então o fundo também não muda.
- **Contraste:** o texto usa `foreground` e `muted-foreground`. Na variante `muted`, o título tem 17,7:1 no claro e 14,3:1 no escuro, e a descrição tem 6,6:1 e 6,1:1. O contorno da variante `outline` (`border`) é decorativo: o Item não é um campo, então não precisa de 3:1.
- **Texto cortado:** o título e a descrição usam `line-clamp` (1 e 2 linhas). O texto cortado continua no HTML e o leitor de tela lê tudo, mas quem vê não lê o resto: não ponha informação que importa depois da segunda linha.

## Item ou Field

Use o `Field` se precisar de um campo de formulário, como uma caixa de seleção, um campo de texto, um grupo de opções ou um select.

Se só precisa mostrar conteúdo, como um título, uma descrição e ações, use o `Item`.

## Link

Use a prop `render` para renderizar o item como um link. O hover e o foco são aplicados ao próprio elemento `<a>`. Para uma ação, use `render={<button type="button" />}`: o foco aparece, mas o fundo não muda no hover.

## Dropdown

Um Item pode ficar dentro de um `DropdownMenuItem`, num menu com mais informação por opção. O menu abre pelo teclado e o foco destaca a opção inteira.

## RTL

Os paddings e o alinhamento são lógicos (`px-*`, `text-start`), então o item segue a direção de um ancestral com `dir="rtl"` sem nenhuma prop. A seta da direção leva `rtl:rotate-180`.

Num app em RTL, coloque `dir="rtl"` e o `lang` no `<html>`. O exemplo usa `dir` num contêiner porque esta página é LTR. Para ver a página inteira em RTL, use o seletor **Direção** na barra de ferramentas. Veja também o [guia de RTL do shadcn](https://ui.shadcn.com/docs/rtl).

### ItemGroup

Agrupa itens relacionados. Tem `role="list"`: os filhos diretos precisam de `role="listitem"`.

### ItemSeparator

Um separador visual entre itens do grupo (veja **Grupo**). O `className` vai para o contêiner; as demais props, para a linha.

### ItemMedia

Mostra mídia, como ícones, imagens ou avatares.

Envolve o título e a descrição do item.

O título do item.

### ItemDescription

A descrição do item, na cor `muted-foreground`. Um link dentro dela fica sublinhado e, no hover, usa o papel `link-hover`, como na FieldDescription.
